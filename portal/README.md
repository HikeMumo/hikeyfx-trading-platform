# Member Portal Preview

Entry point: `portal/index.html`.

This is a static UI prototype for the future HikeyFX member area. It demonstrates the intended account overview, demo account card, member-service navigation, KYC status area and recent activity layout.

It is not connected to authentication, a database, identity verification, customer support or payment systems. All values are illustrative. Do not collect personal documents, passwords or payment details through this page.

Keep it isolated from the public homepage until the user approves integration and the required backend/security work is complete.
